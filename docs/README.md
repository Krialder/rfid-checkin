# Documentation

This directory contains comprehensive system documentation providing setup guides, feature documentation, and operational procedures for the RFID Check-in System.

## Documentation Structure

### Setup & Installation
- **`DATABASE_SETUP_GUIDE.md`** - Complete database setup and configuration guide
- **`SECURITY_SETUP.md`** - Security configuration and best practices
- **`SETUP_GUIDE.md`** - General system setup and deployment guide

### Feature Documentation
- **`RFID_SCANNING_FEATURE.md`** - RFID scanning functionality and hardware integration
- **`IMPLEMENTATION_ROADMAP.md`** - System development roadmap and feature completion status
