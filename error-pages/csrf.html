🛡️ What is a Security Token?

Security tokens (CSRF tokens) protect against unauthorized form submissions and ensure that requests come from legitimate users.

Common causes of this error:

  • The page was open for too long (tokens expire for security)
  • You navigated back to a form after submitting it
  • Multiple browser tabs with the same form
  • Browser cache or session issues

How to resolve:

  • Refresh the page to get a new security token
  • Make sure JavaScript is enabled in your browser
  • Clear your browser cache and cookies if the problem persists
  • Avoid using the back button after form submissions
✅ Quick Fix: Click "Refresh Page" above to automatically get a new security token and continue where you left off.
